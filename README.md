# 🛒 E-Ticaret Bitirme Projesi

Bu depo, **SoftITo Backend Developer Bootcamp** kapsamında geliştirdiğim **E-Ticaret Bitirme Projesi**ni içermektedir.  
Proje; **ASP.NET Core MVC**, **Entity Framework Core** ve **katmanlı mimari** kullanılarak geliştirilmiştir.  

## 🚀 Proje Özellikleri
- Kimlik yönetimi (kayıt, giriş, rol bazlı yetkilendirme)  
- Sepet yönetimi (ürün ekleme, çıkarma, miktar güncelleme)  
- Sipariş oluşturma ve sipariş detaylarını görüntüleme  
- Admin paneli üzerinden ürün, kategori, sipariş, kullanıcı ve rollerin yönetimi  
- Modern, responsive (mobil uyumlu) UI (Bootstrap 5 & FontAwesome)  

## 📂 Katmanlı Mimari
- **ETicaretBusinessKatmanı** – İş mantığı ve validasyonlar  
- **ETicaretDalKatmanı** – Veri erişim (Entity Framework Core ile CRUD işlemleri)  
- **ETicaretDataKatmanı** – Veritabanı modelleri, context, identity  
- **ETicaretUIKatmanı** – MVC tabanlı kullanıcı arayüzü
